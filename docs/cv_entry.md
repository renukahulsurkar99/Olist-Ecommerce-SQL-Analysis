# Olist E-Commerce SQL Analysis

**PostgreSQL, SQL, relational modelling, customer cohorts, data quality, GitHub Actions**

- Developed a PostgreSQL portfolio project across eight related tables, analysing 99,441 orders and 112,650 order items with 15 business queries.
- Used CTEs, window functions, cohort analysis and order-level aggregation to investigate delivery reliability, customer purchasing, product mix and review scores while preventing duplicated monetary totals.
- Identified a 6.77% late-delivery rate among date-eligible delivered orders and a review-score association of 2.27 stars for late orders versus 4.29 for on-time orders, supported by reproducible SQL outputs and automated checks.
